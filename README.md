# ✍️ Системы верификации подписей (PyTorch / Telegram Bot)

## 📌 Описание проекта

Telegram-бот для автоматической верификации, анализа и сопоставления рукописных подписей. Система построена на базе сиамской нейросети (Siamese Network) с использованием архитектуры ResNet, дообученной на датасете CEDAR. Весь тяжелый вес модели вынесен в облако и загружается динамически, обеспечивая легкость репозитория.

## 🛠 Технологический стек

- **Python 3.10+** (основной язык разработки)
- **PyTorch & Torchvision** (фреймворк машинного обучения и работа с изображениями)
- **Hugging Face Hub** (облачное хранилище и динамическая загрузка весов модели)
- **SQLite 3** (база данных для сессий и пользователей)
- **Pillow (PIL) & NumPy** (обработка и преобразование графических данных)

## 📋 Требования

- Python версии 3.10 или новее
- Активное интернет-соединение (для автоматической загрузки весов из Hugging Face)
- Наличие GPU (опционально, для ускорения расчетов через CUDA)
